# Pelaporan keamanan

Laporkan dugaan kerentanan secara privat kepada pengelola repositori. Gunakan fitur pelaporan kerentanan GitHub jika tersedia. Sertakan versi, komponen terdampak, dan dampak yang teramati. Hapus kredensial dan data pribadi dari lampiran.

## Pemeriksaan pengembangan

Pemeriksaan integrasi awal mencakup akses profil privat, profil dilindungi sandi, role subscriber/editor, REST publik, dan peninjauan klaim oleh admin. Audit dependensi npm dan Composer berjalan di CI. Laporan WPCS menyertakan temuan yang perlu ditinjau sebelum rilis. Rangkuman pemeriksaan sumber tersedia di [docs/security-audit.md](docs/security-audit.md).
