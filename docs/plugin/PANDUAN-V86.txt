SEKOLAH DIRECTORY PRO 8.6.0 — MULTI-SOURCE AUTOMATION (BETA)

INSTALASI
1. Backup database dan wp-content di LocalWP. Instal ZIP v8.6.0 via Plugins > Add New > Upload; pilih Replace current with uploaded. Tema v7.0 tetap dapat dipakai. Tidak perlu impor ulang.
2. Pastikan plugin aktif, tabel sekolah dan kolektor tersedia. Periksa wp sdp health melalui Open Site Shell.
3. Buka Direktori Sekolah > Otomatisasi Terpadu. Pilih provinsi wajib; kabupaten/kota, kecamatan, jenjang opsional; tulis nilai persis seperti database. Isi cursor NPSN jika melanjutkan batch sebelumnya. Batas 10 sekolah (mode hemat) atau 30 (standar).
4. Buat kampanye. Tidak ada akses jaringan saat membuat kampanye. Kandidat diurutkan menurut kekurangan data di dalam batch NPSN, bukan seluruh database nasional. Draf/pending yang tidak berpassword dapat dipilih; data demo terdeteksi, privat, trash dan berpassword dikecualikan. Jika tidak ada kandidat, tinjau filter.
5. Lihat NPSN aktif, kebutuhan sumber dan daftar kandidat. Jalankan Proses satu langkah. Untuk akses jaringan, konfirmasi izin sumber setiap kali diperlukan. Untuk portal Referensi Data Pendidikan, periksa robots.txt dan ketentuan secara manual sebelum memberi persetujuan. Jangan melanjutkan jika akses/penggunaan ulang tidak diizinkan.
6. Tahap reference: bila atribut relevan kosong, satu permintaan portal referensi berdasarkan NPSN; identitas diperiksa, kolom kosong relevan diisi melalui SDP_Directory::save dengan policy fill, sumber tercatat. Profil yang sudah terbit dapat langsung berubah; draf tidak otomatis terbit. Tidak menimpa nilai lama. Jika tidak ingin mengakses portal, klik Lewati sumber ini.
7. Tahap website_route/discovery: jika perlu narasi, periksa website. Jika belum tersedia atau tidak cocok dengan syarat crawler, gunakan tautan Penemuan Website, lakukan verifikasi manual atau API Brave opsional, lalu kembali ke Otomatisasi Terpadu dan klik Proses satu langkah. URL lama tidak otomatis diganti; gunakan Validasi & Konflik untuk koreksi. Jika tidak perlu narasi, lanjut ke handoff.
8. Tahap crawler: periksa izin domain dan penggunaan ulang; klik untuk membuat checkpoint, lalu klik lagi untuk robots.txt. Satu permintaan jaringan maksimum per langkah. Tunggu minimal 60 detik atau lebih sesuai robots.txt. Maksimum 5 halaman HTML/pekerjaan (mode hemat), 15 (standar), kedalaman 1 atau 2. Jika server menolak atau parser menemukan masalah, kampanye berhenti/dijeda. Jangan mencoba melewati pembatasan. Bila crawler berhenti atau kedaluwarsa, lanjutkan status lalu lewati sumber atau sekolah; tidak ada retry tersembunyi.
9. Tahap review: pilih Kirim ke pratinjau Website Sekolah per URL. Buka menu Website Sekolah, tinjau bukti, sunting menjadi ringkasan faktual atau teks berizin, hapus informasi pribadi, pilih kolom kosong yang valid, lalu simpan. Pratinjau 15 menit. Jangan menimpa pratinjau lain. Kembali ke Otomatisasi Terpadu; ulangi untuk URL berikutnya. Klik Selesai tinjau setelah selesai atau usulan tidak dibutuhkan. Tidak berarti semua usulan disetujui.
10. Tahap handoff: periksa kebutuhan statistik dan akreditasi; gunakan Sumber Resmi / Pengumpul Data untuk dataset yang diizinkan, atau Validasi & Konflik untuk koreksi. Tidak ada API BAN-PDM/EMIS langsung baru. Klik Proses satu langkah untuk maju ke sekolah berikutnya. Status done hanya berarti alur kampanye ditutup, bukan seluruh atribut terisi. Gunakan cursor yang ditampilkan untuk batch selanjutnya.

MODE HEMAT DAN PENYIMPANAN
- Satu kampanye global; tidak ada cron, worker, asset frontend atau tabel baru. Menggunakan pengunci MySQL kolektor pada tindakan admin. Dalam mode hemat pengunci ini juga dipakai statistik. Antrean kolektor pending dan kampanye Mesin Pengayaan auto yang aktif memblokir langkah baru. Bukan pengunci universal semua pekerjaan WordPress.
- Checkpoint kampanye disimpan pada option sdp86_campaign dengan autoload false. Data crawler disimpan dalam transient terpisah maksimal 24 jam dari penciptaan; transient dapat hilang lebih awal. Saat dibatalkan atau berganti sekolah data crawler dibersihkan; pratinjau Website Sekolah terpisah dan harus dibuang bila tidak dibutuhkan. WordPress transient kedaluwarsa tidak selalu dihapus fisik tepat waktu.
- Crawler memakai pembatas v8.5; portal referensi memakai batas lama 2 MiB dan timeout 20 detik, serta jeda minimal 60 detik. Batas jaringan ini bukan kuota total bandwidth VPS. Mode standar dapat diaktifkan dengan define('SDP_LOW_RESOURCE', false); sesudah benchmark atau di LocalWP yang memadai.
- Mode hemat default cocok sebagai titik awal RAM 1 GB, CPU terbatas; kuota bandwidth 10 GB belum diketahui periodenya. Pengumpulan berat lebih baik dilakukan lokal. Tidak ada pengaturan sumber daya otomatis mengikuti trafik pada versi ini.

UJI LOCALWP (JANGAN LANGSUNG PRODUKSI)
- Uji satu profil nyata dari dataset berizin pada situs lokal. Jika belum punya izin sumber, gunakan Lewati sumber atau uji tanpa jaringan. Jangan gunakan NPSN fiktif yang menyerupai sekolah nyata untuk melakukan permintaan jaringan.
- Pastikan kandidat terpilih sesuai filter; coba klik ganda formulir lama, harus ditolak setelah checkpoint berubah. Coba jeda/lanjut/lewati/batalkan. Pastikan profil lama tidak hilang dan tidak diduplikasi.
- Uji kolom kosong vs nol, placeholder dan atribut terkunci. Uji perubahan website atau status profil di tengah kampanye. Pastikan sumber dan periode tetap benar.
- Uji satu langkah crawler pada sumber berizin: robots.txt, jeda, pratinjau, penyimpanan usulan terpilih. Uji bahwa profil privat/password tidak ikut kampanye.
- Periksa RAM, CPU, error log, query lambat dan transfer jaringan di server uji. Lakukan backup sebelum dan sesudah.

BATASAN
Belum diuji di WordPress/MySQL/LocalWP nyata. Pengujian simulasi PHP mencakup jalur reference tanpa perubahan (bukan penulisan nyata), HTTP 429, NPSN berbeda, route, checkpoint, parser HTML dan handoff. DNS, jaringan nyata, lock MySQL, UI, integrasi autentikasi, penyimpanan profil dan performa belum diverifikasi. Tidak ada scheduler baru; v8.7 adalah tahap lanjutan. Tidak ada penyedia data pemerintah baru, tidak ada crawl lintas domain, tidak ada publikasi narasi otomatis. Tidak ada jaminan keamanan/kapasitas produksi. 677 pemeriksaan versi lama adalah hasil historis, suite lengkap tidak tersedia untuk dijalankan ulang pada rilis ini.
