SEKOLAH DIRECTORY PRO 8.2.0 — Excel & XLSX Importer

Kebutuhan: WordPress 6.4+, PHP 8.0+, ZipArchive dan XMLReader untuk konversi di WP Admin. Jika ekstensi tidak tersedia, gunakan konverter Python 3.8+ lokal yang disertakan (hanya standard library), atau simpan Excel sebagai CSV UTF-8. Tidak ada cron, layanan eksternal, maupun library baru yang selalu berjalan. Mode hemat v8.1 tetap default.

1. Cadangkan database serta wp-content. Upload ZIP pada Plugins > Add New Plugin > Upload Plugin; Replace current with uploaded. Aktifkan. Tema 7.0 tetap.
2. WP Admin > Direktori Sekolah > Impor Excel. Pilih .xlsx, nomor sheet (1-based), konfirmasi hak pemakaian dataset, klik Konversi dan unduh CSV.
3. Periksa CSV memakai editor teks, bukan membuka/menyimpan ulang dengan Excel yang dapat mengubah NPSN. Di Pengumpul Data, pilih format CSV, isi nama sumber, filter wilayah/jenjang, jenis dataset, mode isi kolom kosong, nonaktifkan terbit langsung untuk awal. Unggah CSV dan pratinjau; unggah kembali dan antrekan jika sesuai. Proses melalui tombol batch. Tidak ada perubahan profil pada tahap konversi.
4. XLSX: header pertama yang tidak kosong; nama kolom sesuai template/alias. NPSN 8 karakter sebagai teks, tanggal sebagai teks ISO (format sel tanggal tidak diterjemahkan; angka serial Excel bukan tanggal ISO). Angka tanpa pemisah ribuan. Sel kosong berbeda dari 0. Formula, sel error, teks menyerupai formula, makro XLSM, XLS lama, enkripsi, sebagian variasi OOXML tidak didukung. Simpan sebagai nilai, hapus judul/kolom kosong yang mengganggu. Tidak menghitung formula. Tidak mengunduh relasi eksternal. Batas 150 kolom, 32 KiB per sel, 100 pilihan sheet.
5. Mode hemat: XLSX max 2 MiB, bagian worksheet/shared strings masing-masing max 4 MiB, hasil CSV max 2 MiB dan 1000 rekaman; mode standar 5 MiB, bagian XML 12 MiB, CSV 5 MiB dan 10000 rekaman. Shared strings dibatasi 30000/100000. XMLReader membaca XML terbatas di memori; bukan streaming XLSX tanpa batas. Header dan satu sheet saja. Konversi berlangsung hanya saat diminta, bukan di setiap kunjungan.
6. Untuk file lebih besar, ekstrak ZIP di komputer. Jalankan dari terminal:
   python tools/xlsx_to_csv.py "D:/data/sekolah.xlsx" "D:/data/sekolah.csv" --sheet 1 --authorized
   Konverter lokal tidak memerlukan pip. Maksimal berkas 32 MiB, XML per bagian 32 MiB, 100000 baris, 300000 shared strings. Tujuan CSV harus baru. Pecah dataset yang melebihi batas. Gunakan Python 3.8+; Windows mungkin memerlukan perintah py, bukan python. Konverter hanya menghasilkan CSV, tidak menulis database.
   Dari LocalWP > Open Site Shell:
   wp sdp import "D:/data/sekolah.csv" --authorized=1 --source="Dataset resmi" --limit=100 --user=admin
   Ulangi perintah sama sampai selesai; checkpoint berdasarkan hash CSV dan konfigurasi. Profil baru draf secara default. Jika diperlukan --provinsi, --kabupaten, --jenjang, --kind. Jangan gunakan --restart kecuali sengaja mulai ulang. Sesuaikan username admin. Untuk CSV besar, jalur CLI lebih cocok daripada unggah browser.
7. VPS RAM 1GB: pertahankan SDP_LOW_RESOURCE=true (default), nonaktifkan jaringan cron kecuali diperlukan. Pengolahan Excel besar di LocalWP, bukan VPS. Setelah VPS di-upgrade dan benchmark menunjukkan cukup kapasitas, set define('SDP_LOW_RESOURCE', false); di wp-config.php sebelum WordPress dimuat. Tidak ada autoscaling otomatis berdasarkan jumlah visitor, dan mode hemat tidak menjamin batas penggunaan RAM/bandwidth server. Hindari memindahkan seluruh DB lokal menimpa data pengguna/operator di produksi; gunakan impor terpilih dan backup.
8. Pengujian: 489 regresi mode standar + 28 mode hemat + 1 network opt-in, 12 pemeriksaan fungsi PHP baru dan 13 konverter Python baru lulus. PHP ZipArchive/XMLReader tidak tersedia pada lingkungan pengujian, sehingga parser XLSX PHP belum dieksekusi end-to-end. Pengujian langsung WordPress/MySQL, upload HTTP, dan benchmark VPS tetap diperlukan. Gunakan data fiktif di lokal privat sebelum data nyata. Tidak ada perubahan tabel baru atau konektor pemerintah baru.
