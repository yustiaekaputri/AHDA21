SEKOLAH DIRECTORY PRO 2.0.0 — PANDUAN KOLEKTOR

UPGRADE: cadangkan situs dan database terlebih dahulu. Di WP Admin > Plugins > Add New > Upload Plugin, pilih ZIP 2.0.0. Pilih Replace current with uploaded jika diminta. Folder dan post type sama dengan 1.0; tidak perlu uninstall. Buka WP Admin supaya tabel antrean dibuat dan cron didaftarkan. Semua data lama tetap berada di tabel sekolah yang sama. Jika tabel tidak muncul, periksa izin database dan log PHP. Jangan menghapus data lama untuk upgrade.

UJI LOKAL (data FIKTIF):
1. Direktori Sekolah > Pengumpul Data. Nama sumber: Demo fiktif. Format CSV. Provinsi bawaan: Jawa Barat. Filter kabupaten: Kabupaten Indramayu. Mode Isi kolom kosong. Jangan centang terbitkan, kecuali pada situs uji yang tidak dipublikasikan. Simpan konfigurasi.
2. Pilih file contoh/dataset-kolektor-fiktif.csv (disertakan dalam ZIP). Centang izin. Klik Pratinjau: 3 dibaca, 2 valid, 1 tidak cocok. Tidak ada profil berubah.
3. Pilih file lagi, centang izin, Unggah dan antrekan. Klik Proses 20 sekarang. Periksa 2 profil draf atau terbit sesuai pilihan. Impor ulang tidak menambah NPSN baru.
4. Ubah format ke JSON, jalur JSON data.items, kosongkan seluruh filter dan nilai bawaan, nama sumber Demo pelengkap. Simpan. Unggah contoh/pelengkap-fiktif.json. Centang izin; pratinjau, unggah lagi dan antrekan. Proses. Profil yang sama mendapat data jumlah guru dan luas tanah. Jika NPSN belum ada dan tidak ada nama, proses akan gagal sampai identitas diimpor. Filter wilayah pada feed pelengkap tanpa kolom wilayah harus dikosongkan.
5. Hapus seluruh data demo dan log demo sebelum produksi. Profil yang sudah terbit tetap terbit saat diperbarui, sekalipun opsi publikasi tidak dicentang.

DATA NYATA: https://data.kemendikdasmen.go.id/data-induk/satpen/daftar dan https://data.kemendikdasmen.go.id/data-induk/pd/jumlah-per-satuan-pendidikan merupakan portal dengan data yang dapat dilihat/diunduh. Unduh CSV jika tersedia dan izin memungkinkan penggunaan ulang. Pilih cakupan yang kecil terlebih dahulu. Jika file Excel, simpan sebagai CSV UTF-8. Tidak ada konektor resmi terverifikasi untuk langsung menarik data dari situs-situs tersebut. URL halaman HTML tidak dapat digunakan sebagai feed. Untuk sinkronisasi otomatis, masukkan URL HTTPS langsung yang benar-benar memberikan CSV/JSON (tanpa autentikasi), simpan konfigurasi dengan jadwal dan konfirmasi izin. Hanya satu konfigurasi terjadwal tersimpan; sumber lain bisa diimpor satu per satu. Jadwal tidak menjamin data sumber lebih baru. Tidak ada crawler/scraper HTML, API key, bypass login atau API tak terdokumentasi.

MAPPING: alias umum NPSN, Nama Satuan Pendidikan, Nama Sekolah, Bentuk, Kota/Kab, Nama Kabupaten Kota, BPS Nama Kecamatan, Peserta Didik, Rombel, Pembina dll. Bentuk lebih spesifik daripada Jenjang. Gunakan mapping JSON target->header jika perlu. Contoh {"nama":"Nama Sekolah","jumlah_siswa":"Peserta Didik"}. Format angka tanpa pemisah ribuan; titik desimal. Nilai kosong, '-', null, n/a diabaikan. Kolom tak dikenal tidak dimasukkan. Filter nama persis, tidak peka huruf besar/kecil; prefix Kab./Kabupaten tidak disamakan. Provinsi/jenjang bawaan hanya untuk sumber yang cakupannya benar-benar diketahui. Tidak ada standardisasi kode wilayah otomatis. Pratinjau menunjukkan maksimal 3 contoh, hingga 10 error dan jumlah data. Untuk data pelengkap, jangan memfilter pada kolom yang tidak ada.

ATURAN GABUNG: Isi kolom kosong menjaga nilai yang sudah ada, termasuk 0. Perbarui kolom yang dikirim dapat mengganti nilai lama; pastikan sumber lebih baru dan benar. Nilai kosong tidak menghapus data lama. Sumber per atribut baru/berubah dicatat dalam payload dan ditampilkan berkelompok pada artikel. Sumber data lama yang tidak mempunyai catatan per atribut tidak dianggap telah diverifikasi. Tanggal data harus berasal dari dataset, bukan tanggal pengambilan. Tidak ada histori perubahan lengkap. Jangan memasukkan data pribadi siswa. Tidak ada verifikasi fakta eksternal otomatis.

ANTREAN: Maksimum 5 MB dan 10.000 rekaman per dataset; pemrosesan maksimal 20 per putaran atau sekitar 15 detik sebelum rekaman berikutnya. Antrean tersimpan di database. Hanya satu antrean aktif; selesaikan/batalkan sebelum menambah sumber lain. Kesalahan validasi saat parsing tampil dalam laporan/pratinjau, bukan tabel log. Log 50 terbaru; tombol retry mengulang kegagalan yang sudah masuk antrean (perbaiki penyebab dahulu), bersihkan log selesai/gagal secara berkala. Tidak menghapus profil saat log dihapus. Jika staging database terhenti, sebagian rekaman mungkin sudah diantrekan; selesaikan lalu ulang impor. Tidak ada jaminan transaksi atomik lintas tabel WordPress.

WP-CRON: interval 5 menit; sinkronisasi URL harian ketika antrean kosong. LocalWP harus berjalan dan ada request ke situs agar WP-Cron dipicu. Jika tidak, klik Proses 20 sekarang; jangan anggap cron berjalan saat komputer mati. Tidak ada sistem realtime. Untuk 10.000 rekaman, 20 per 5 menit membutuhkan lebih dari satu hari jika hanya mengandalkan cron; ini bukan benchmark nasional. Batas server PHP bisa lebih kecil dari 5 MB.

PENGUJIAN: lint PHP dan smoke test parser/mapping/filter/merge dengan stub WordPress. Belum diuji langsung pada WordPress/MySQL/LocalWP nyata, belum dilakukan fetch langsung dari feed pemerintah, belum benchmark nasional. Jangan langsung gunakan pada situs produksi. Fitur sebelumnya tetap tersedia; edit manual konten profil masih dapat tertimpa regenerasi. Uji backup/restore.
