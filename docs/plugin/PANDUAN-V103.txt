SEKOLAH DIRECTORY PRO 10.0.0-rc.3 — 25 November 2026
Kandidat integrasi data, staging. Belum versi produksi stabil.

PERUBAHAN
- tools/prepare_pilot.py: membaca konfigurasi JSON dan menjalankan validator RC2 untuk masing-masing CSV. Pilih provinsi + kabupaten/kota dengan nama persis (case-insensitive), urutkan NPSN, ambil hingga 100. Sumber pelengkap dicocokkan hanya berdasarkan NPSN dan dipisah agar periode dan asal data tidak tercampur. Semua input wajib lulus validasi; data di luar pilot tidak dimasukkan. Manifest memuat cakupan, sumber, edisi, dasar izin yang dinyatakan pengguna, hash file asli dan hash keluaran. Folder harus baru; jika terjadi I/O error saat menulis, buang folder parsial dan ulangi. Maks 1.000 baris/2 MiB per file input; bagi file besar terlebih dahulu di komputer lokal.
- Validator RC2: tambahan alias peserta_didik dan guru, penolakan awalan NPSN DEMO dan SIMU.
- WP-CLI `wp sdp pilot-preview`: baca saja, maksimal 100 rekaman, membutuhkan hash SHA-256 CSV keluaran pilot. Hanya WP_ENVIRONMENT_TYPE=local, blog_public=0 dan user dengan manage_options. Tidak ada jadwal, tabel, aset publik atau permintaan HTTP baru. Tidak menulis data sekolah atau mengunci snapshot. Lakukan di clone yang tidak dipakai oleh pengguna lain.

PERSIAPAN PILOT DI KOMPUTER LOKAL
1. Cadangkan WordPress dan DB. Clone LocalWP khusus pengujian, nonaktifkan indeks, scheduler/otomatisasi. Upgrade dengan ZIP plugin di dalam paket (bukan ZIP paket lengkap). Tema v7.0 tetap sama.
2. Ambil CSV resmi berizin. Gunakan template konfigurasi sdp-rc3-konfigurasi-pilot.json. Kolom rights sengaja kosong; isi hanya jika dasar izin benar-benar telah dipastikan untuk penggunaan yang dimaksud. Ubah edisi sesuai sumber aktual. Tambahkan statistik/akreditasi opsional sebagai objek dengan file, source (HTTPS tanpa query), edition, rights. Untuk XLSX konversi dengan alat RC2; gunakan UTF-8. Jangan menebak provinsi/jenjang atau mencampur kolom kode BPS dan Kemendagri. Jika sumber memiliki dua nama kecamatan, pilih sistem yang sesuai dan catat pemetaan. Kolom jenjang yang berisi bentuk spesifik membutuhkan canonical_form: true. Tidak menerima jenjang umum DIKDAS sebagai bentuk sekolah. Lihat PANDUAN-V102.txt.
3. Jalankan dari folder paket:
   python sdp-prepare-pilot.py sdp-rc3-konfigurasi-pilot.json pilot-output --limit 100
   Folder pilot-output harus belum ada. File validate_source.py (nama impor Python) harus berdampingan dengan skrip. Di plugin, pakai tools/prepare_pilot.py. Simpan manifest dan dataset asal lokal. Tidak ada data yang ditulis ke WordPress. Cakupan dihitung per NPSN, bukan verifikasi fakta atau izin.
4. Salin CSV identity.csv ke lokasi yang bisa diakses Site Shell LocalWP. Gunakan SHA-256 `sources.identity.sha256_pilot` dari manifest:
   wp sdp pilot-preview "PATH/identity.csv" --kind=identity --sha256=HASH_DARI_MANIFEST --user=admin
   Ganti admin dengan username admin clone, dan path/hash dengan nilai asli. Untuk pelengkap, gunakan file statistics.csv/accreditation.csv dan hash sumber yang bersesuaian, setelah identitas tersimpan.
5. Baca hasil: new_identity (calon baru); fill_candidate (atribut kosong); unchanged (nilai sama); missing_identity (pelengkap tanpa profil); conflict_review (nilai berbeda); locked_review (atribut terkunci); period_review (periode lama tidak sama/diketahui); non_draft_review (status bukan draft/pending); broken_profile (relasi/payload tidak konsisten). Tidak ada perubahan otomatis. Jika ada konflik, jangan mengimpor batch sebelum diselesaikan. Preview tidak membuktikan identitas statistik selain NPSN dan tidak mencegah perubahan setelah pemeriksaan.
6. Hanya setelah pemeriksaan, gunakan Sumber Resmi > jenis general untuk identity, statistics/accreditation untuk pelengkap. Mode fill, publikasi langsung mati, jadwal mati, konfirmasi izin. Periksa pratinjau, antrekan, jalankan batch terbatas. Jangan masukkan ke situs publik. Importer lama tidak diwajibkan memakai preview; tidak ada mekanisme penguncian manifest. Jangan impor batch berisi profil publik, privat, atau konflik sebelum pemeriksaan; importer lama dapat mempertahankan status publik yang sudah ada. Nama sumber/edisi harus diisi jelas; simpan manifest terpisah karena provenance URL pada import upload/CLI lama belum otomatis dari manifest.
7. Ulangi preview untuk NPSN yang sama, audit `wp sdp readiness --audit`, dan lakukan smoke test RC1 pada clone. Verifikasi bahwa satu NPSN hanya punya satu profil, status draf, statistik dan akreditasi benar, serta tidak ada data individu. Catat hasil dan kirimkan untuk RC4.
